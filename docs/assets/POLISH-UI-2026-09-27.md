This pass translates the reviewed Atomic Acres UI board into the existing menu
shell. The reference is an art direction cue for material, hierarchy, and
spacing; it does not introduce game copy, weapons, streaks, map options, or HUD
state.

## Visual translation

- Main menu uses a bounded warm ivory instrument panel with charcoal type, teal
  hierarchy, amber selection/focus, and fine rules. A light directional scrim
  leaves the authored map visible behind it. A static line texture adds
  material character without a canvas, blur, or animation loop.
- Existing map cards stay the source of truth and remain inside the existing
  `MapSelect` handle. The new mission strip only groups the map heading and
  cards for layout and assistive labelling.
- Pause, credits, end, deploying, and error views share the same command-card
  frame. The scoreboard keeps its current rows, names, score values, and update
  cadence.
- The existing matchbar, ammo plate, and streak cards receive only the same
  ivory-on-charcoal, teal-normal, amber-ready, and red-low color/border family;
  their positions, labels, state classes, and pointer behavior are unchanged.
- Buttons, credits/licence lines, keyboard prompts, reduced-motion behavior,
  and the overlay's click contract remain owned by the existing shell.

## Owned paths

- `src/ui/menu-views.ts` adds only stable semantic classes and wrappers around
  existing handles.
- `src/ui/concept-polish.css` is a new additive stylesheet. The root should
  import it after `menus.css` when integrating this pass.
- `scripts/_verify-concept-ui.mjs` performs CPU-only source assertions.

Actual pixels remain OPEN until the root performs its independent browser and
capture checks. No GPU, browser, render, input, process, or dependency job is
part of this source pass.
