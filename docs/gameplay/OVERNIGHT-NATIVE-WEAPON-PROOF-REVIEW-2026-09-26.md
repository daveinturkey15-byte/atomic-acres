2. **OPEN — [P2] Reload admission is proved, but exact completion/conservation is not.** Harness lines 334–342 record only host state before and during native R reload. Retain the completed host state and assert that magazine gain equals reserve loss, total rounds stay constant across reload, and the reload marker clears before the next shot. This is a native-proof gap; current host source at `host-weapon-state.ts:95–101` does subtract reserve correctly, and separate CPU tests contain conservation assertions.

3. **OPEN — [P2] Drone trigger state is local intent, not admitted aircraft fire.** Harness lines 392–397 assert `firing.pilot.firing` plus unchanged body kit. `src/core/pilot-controls.ts:118–120` exposes the local `fire` flag, and `lastSentAt` is a send timestamp. 4. **OPEN — [P2] Loaded-entry binding still hashes a second request.** Harness lines 261–266 now verifies the actual module URL's pathname, which fixes the initial absence of any page-entry comparison.
