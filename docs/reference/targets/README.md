## The one rule

**Targets are a comparison aid for critics. Nobody copies pixels from them.** They are OUR
frames re-rendered by an image model, never frames of the source game; nothing in them may
carry the source game's name, logos or HUD (the prompts refuse text/logos/HUD and B5 in
`docs/night/VISUAL-BAR.md` still applies to anything that slips through). Nothing here enters
`public/` or `src/`. A target that shows a *different* street - re-composed, re-cropped, with
invented objects - is worthless however beautiful, which is what the fidelity gate is for.

## How to regenerate

```
# 1. sources - builds ONCE, records the bundle hash, captures 10 stations (viewmodel hidden,
#    __NT.goto, one post-chain render) + playcap's 4 positions (real loop, overlay clicked,
#    viewmodel shown), Math.random seeded so the 43 canvas textures repeat. Real Chrome over
#    CDP (playwright's chromium has no WebGPU). If dist/ changes under the page between the
#    two loads the whole set is re-captured; the manifest records the bundle both ways.
node scripts/art-gen/photoreal-targets.mjs capture            # add --no-build to reuse dist/

# 2a. route A (primary): agy -> Gemini -> generate_image with the frame as ImagePaths, 16:9
node scripts/art-gen/photoreal-targets.mjs route-a           # --only id,id  --force  --agy-model m

# 2b. route B (local fallback / alternates): ComfyUI Qwen-Image-Edit-2511 image-to-image
python scripts/art-gen/photoreal-targets.py batch --denoise <see below>   # writes targets/ or, with
                                                                          # --out-sub alt-b, alt-b/
python scripts/art-gen/photoreal-targets.py free             # give the owner his VRAM/RAM back

# 3. gate + numbers + manifest
python scripts/art-gen/photoreal-targets.py fidelity sources/x.png=targets/x.png ...
python scripts/art-gen/photoreal-targets.py report          # MANIFEST.md + deltas.json
```

Machine courtesy is built in: `windowsHide` on every spawn, `spawnGuarded`/`killTree`, the
shared `:4188` preview (never `:4190`, never `:4173`), one browser at a time, a hard timeout on
every external call (agy `--print-timeout` + a kill timer; ComfyUI a poll cap per prompt), the
ComfyUI slot gate (`GET /queue` idle AND `nvidia-smi` >= 8 GiB free, or the resident VRAM is
provably our own cached model set) before every submit, outputs copied out of ComfyUI's
output folder at once (it is swept every 2 h), `POST /free` at the end.

## Route A - the Antigravity CLI bridge (what the owner asked for) - WORKS

`agy --print "<prompt>" --model gemini-3.1-pro-high --effort high --dangerously-skip-permissions
--print-timeout 600s`, one frame per invocation in its own scratch directory (agy reads and
writes its cwd). `agy models` (07:00) listed gemini-3.8-flash-*, gemini-3.7-flash-*,
gemini-3.6-flash-*, gemini-3.1-pro-{high,low}, claude-sonnet-4-6, claude-opus-4-6-thinking,
gpt-oss-120b-medium; 3.1 Pro is the most capable Gemini and it drives an image tool.

Two probes on `station-turningHead` decided the prompt shape:

| attempt | prompt | what came back | gate |
|---|---|---|---|
| 1 | "read source.png, write a photoreal re-render to target.png" | `DONE target.png / Tool used: generate_image / Model used: Gemini 3.1 Pro (High) / Imagen` - a **1024x1024** image, camera re-composed, a red trolley and a blue cart invented in the foreground | **FAIL**: aspect changed, edge overlap 0.439, 4 moved blocks |
| 2 | asked for the tool's parameters and an img2img call | `TOOL-PARAMS: ImagePaths (ARRAY ... images to use in generation ... to edit, combine, or use as references)`, `AspectRatio ('1:1','2:3','3:2','3:4','4:3','9:16','16:9')`, `ImageName`, `Prompt (... or the edit instructions)`; then `DONE target.png Gemini 3.1 Pro (High)` - **1376x768**, same camera, same objects | **PASS**: edge overlap 0.805, SSIM 0.722, 0 moved blocks |

So the production prompt tells the agent to call `generate_image` once with
`ImagePaths=[source.png]`, `AspectRatio '16:9'`, and the re-render instruction. The tool exposes
no seed; every sidecar says so (`seed: null`) and keeps the verbatim agent transcript
(`agyLog`). Outputs are resized 1376x768 -> 1600x900 (Lanczos) so pairs are pixel-aligned.
First launch of the batch failed in 0.1 s per frame with *"Prompts are read only from
-p/--print ..."*: the prompt had been passed through `cmd.exe` (`shell:true`) and split on
spaces. `agy` is `agy.exe`; spawn it directly.

## Route B - local ComfyUI, Qwen-Image-Edit-2511 - works, but stays close to the render

ComfyUI 0.34.0 on `:8188` (owner's, never restarted), RTX 5080 16 GiB. Graph = the shipped
template `image_qwen_image_edit_2511.json` (templates 0.11.52) flattened to API form, LoRA
switch OFF (the Edit-2511 Lightning LoRA is not on disk): UNETLoader
`qwen_image_edit_2511_fp8_e4m3fn` -> ModelSamplingAuraFlow 3.1 -> CFGNorm 1.0; CLIPLoader
`qwen_2.5_vl_7b_fp8_scaled` (qwen_image); VAELoader `qwen_image_vae`; LoadImage ->
FluxKontextImageScale (1600x900 -> 1392x752) -> TextEncodeQwenImageEditPlus (positive and
negative, image1 = the frame) -> FluxKontextMultiReferenceLatentMethod index_timestep_zero;
VAEEncode of the scaled frame as the latent; KSampler euler/simple, 20 steps, cfg 4.0, fixed
seed; VAEDecode; resized back to 1600x900. The one deviation from the template is `denoise`.

Calibration on `station-turningHead`, seed 20260919 (93-115 s per image, the whole card):

| denoise | edge overlap | SSIM | what it looks like |
|---|---|---|---|
| 0.35 | 0.871 | 0.774 | our render, cleaned; no material change |
| 0.60 | 0.868 | 0.771 | cracks drawn into the asphalt, otherwise our render |
| 0.80 | 0.854 | 0.745 | cracks, oil stains, grime on the coach, a little haze; still flat-shaded low-poly |
| 1.00 | see MANIFEST | | |

The edit model treats the frame as the truth and adds surface detail on top; it does not
re-light or re-materialise the way route A does. Composition is therefore never the problem
on route B (every denoise passed the gate); photoreal *gain* is. It is the fallback when agy
is unavailable or over quota, and its outputs are filed as `alt-b/` alternates where they add
detail (asphalt cracking, grime, decals) the critics can point at.

## The fidelity rule (run before the verifier does)

`photoreal-targets.py fidelity source=target` on every pair, at the generated size:

- **Edge overlap** - both images to 800x450 grey, 3-tap blur, Sobel magnitude, each image's
  own top-10 % gradient pixels form its edge set, dilate 2 px, score = mean of (source edges
  found in target, target edges found in source). **Bar: >= 0.55.**
- **Moved geometry** - the source edge mask cut into a 6x8 grid; a block with at least the
  median edge density whose edges find < 35 % of themselves in the dilated target mask has
  "moved". **Bar: <= 2 such blocks.**
- **Aspect** - a target whose aspect ratio differs by > 2 % was re-composed, not re-rendered.
  **Bar: fail.**
- **SSIM** at 200x112 grey, 7x7 window - recorded, not gated (a photoreal target is *meant*
  to differ in texture).

Calibration of the gate itself, so its numbers mean something: identical frame 1.000;
`turningHead` vs `midStreet` 0.316; vs `playcap-circle` 0.388; `spawnA` vs `spawnB` 0.367 -
a different view of the same street scores 0.32-0.39, so 0.55 is well clear of it. Route A
attempt 1 (re-composed) scored 0.439 and failed on three counts; attempt 2 scored 0.805.

A rejected pair is regenerated (route B: denoise -0.10 down to 0.15; route A: one more
attempt), and a pair that passed is never regenerated by a later run (`--force` to override).

## What the measurements are (deltas.json, GAP-*.md)

`photoreal-targets.py measure --regions regions.json` on each pair, same rectangles on both
images (display-referred 8-bit values - read relationships, not absolutes):

luma p5/p50/p95 · fraction of pixels below 20 % and above 90 % luma (S2) · mean HSV
saturation and a McCamy CCT of the frame mean (S7) · sunlit:shaded ratio on ONE material
(S2) · shadow edge 10-90 % width in px across a named shadow line (S1/S8) · sky top-fifth vs
horizon-fifth RGB and luma gradient (S5) · contact darkening under a named object vs the same
surface a few metres away (S1) · mean Sobel magnitude on a flat facade rect (S3/S4 micro-detail).
`regions.json` says which rectangle is which; five stations needed a second pass because
the first guess had lit and shaded inverted (see its `_note` fields).
